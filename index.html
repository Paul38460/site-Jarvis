Assistant personnel pour Windows 11

J.A.R.V.I.S

Un assistant qui vous comprend en français : il ouvre vos logiciels, retrouve vos fichiers, gère vos notes et vos rappels, lit vos e-mails et vous répond — avec une intelligence artificielle qui tourne sur votre propre PC.

Lire les prérequis d'abord ↓

Version 3.0.0 · Aucun abonnement · Aucune API payante · Aucune donnée envoyée à l'auteur

Cette page est affichée dans un aperçu intégré. Les navigateurs y bloquent presque toujours les téléchargements, sans message. Ouvrez-la dans un vrai onglet de Microsoft Edge, Chrome ou Firefox (ou enregistrez ce fichier sur votre PC et double-cliquez dessus).

Lien direct vers le fichier : JARVIS-3.0.0.zip

Ce système n'est pas Windows. JARVIS est conçu pour Windows 11 : vous pouvez le télécharger ici, mais il ne fonctionnera pas sur macOS, Linux, Android ou iOS.

Avant de télécharger : 3 choses à installer

JARVIS a besoin de deux logiciels gratuits sur votre PC. Installez-les d'abord (comptez 10 minutes), puis revenez ici.

1Python 3.13

Le moteur qui fait tourner JARVIS.

Télécharger Python ↗

  • Pendant l'installation, cochez « Add python.exe to PATH » et « py launcher ».
  • Laissez « tcl/tk and IDLE » coché (nécessaire à l'interface).
  • Python 3.13 est recommandé : avec une version plus récente, le micro peut ne pas s'installer.

2Ollama

L'intelligence artificielle locale : elle répond à vos questions et résume vos e-mails, sans rien envoyer sur Internet.

Télécharger Ollama ↗

  • Après l'installation, JARVIS utilise le modèle qwen2.5:1.5b (environ 1 Go).
  • L'installateur de JARVIS peut le télécharger pour vous, avec votre accord. Sinon, tapez dans une console :
ollama pull qwen2.5:1.5b

Sans Ollama, JARVIS fonctionne pour les commandes (ouvrir, chercher, notes, rappels…), mais sans conversation IA ni résumés intelligents.

3Votre ordinateur

  • Windows 11 (Windows 10 : non testé ; macOS et Linux : non pris en charge).
  • Environ 3 Go d'espace libre (Ollama + modèle) et 8 Go de mémoire vive recommandés.
  • Un micro, si vous voulez parler à JARVIS (facultatif : tout marche aussi au clavier).
  • Une connexion Internet pour l'installation, pour la reconnaissance vocale (service Google) et pour Gmail.

Facultatif : un compte Gmail (pour les e-mails) et LibreOffice (si vous l'utilisez).

Installer JARVIS en 4 étapes

Une fois Python et Ollama installés :

  1. 1Télécharger

    Le fichier ZIP de JARVIS (173 Ko).

    Le téléchargement ne démarre pas ?
    • Ouvrez la page dans un vrai onglet de Microsoft Edge, Chrome ou Firefox : pas dans un aperçu intégré, une messagerie ou un éditeur de texte.
    • Regardez la liste des téléchargements du navigateur (Ctrl+J) : Edge ou Chrome peuvent demander de confirmer (« Conserver »).
    • Essayez une fenêtre de navigation privée : une extension ou un antivirus peut bloquer le téléchargement.
    • Utilisez le lien de secours : clic droit sur JARVIS-3.0.0.zip, puis « Enregistrer le lien sous… ».
    • Si un « lien direct » est affiché en haut de page, il télécharge le fichier sans passer par le script.

  2. 2Extraire le ZIP

    Clic droit sur le fichier ZIP, puis « Extraire tout… ». Windows propose un dossier de destination : laissez-le tel quel (un nouveau dossier est créé, par exemple JARVIS-3.0.0), ou choisissez un dossier vide de votre choix. N'extrayez pas par-dessus une ancienne version et ne lancez pas JARVIS depuis l'intérieur du ZIP.

    Ouvrez ensuite le dossier créé : vous devez y voir installer_jarvis.bat, lancer_jarvis.bat, main.py, README.md, les fichiers requirements… et deux dossiers, jarvis et tests. Si vous ne voyez que main.py, voyez la question « L'extraction est incomplète » plus bas.

  3. 3Lancer l'installateur

    Double-cliquez sur installer_jarvis.bat. Il détecte Python, prépare un environnement dédié, installe la voix et le micro, vérifie Ollama et propose un raccourci sur le Bureau. Il ne télécharge le modèle d'IA qu'avec votre accord.

    Windows peut afficher « Windows a protégé votre PC » : cliquez sur Informations complémentaires, puis Exécuter quand même. Les fichiers .bat sont du texte lisible : vous pouvez les ouvrir avec le Bloc-notes pour vérifier ce qu'ils font.

  4. 4Démarrer

    Double-cliquez sur lancer_jarvis.bat (ou sur le raccourci Bureau). Tapez « aide » ou cliquez sur ÉCOUTER et dites « Bonjour ». En cas de souci : lancer_jarvis.bat --diagnostic affiche l'état de chaque composant.

Ce que JARVIS sait faire

Des fonctions réelles, pensées pour un usage quotidien. Tout se commande à la voix ou au clavier.

Interface futuriste

Réacteur animé qui réagit à chaque état (écoute, réflexion, parole), tableau de bord réel, 5 thèmes, plein écran.

Comprend le français naturel

Distingue un ordre d'une question : « Pourquoi YouTube ne marche pas ? » n'ouvre rien. Comprend « ne lance pas YouTube, ouvre plutôt mes documents ».

Voix et micro

Répond à voix haute (réglable), vous écoute en français, mode silencieux, interruption à tout moment.

IA locale (Ollama)

Conversations, explications et résumés générés sur votre PC. Le modèle ne peut jamais exécuter d'action de lui-même.

Vos logiciels Windows

Détecte les logiciels installés et les ouvre par leur nom : « ouvre Steam », « lance VLC ».

Fichiers et dossiers

« Trouve mes PDF dans Téléchargements », « ouvre le deuxième », « ouvre le dossier correspondant ».

Notes, rappels, mémoire

Notes modifiables, minuteurs, rappels datés conservés si JARVIS est fermé, souvenirs que vous lui demandez de retenir.

Google et Edge

Recherches Google, YouTube, Bing, Wikipédia ; ouverture de sites ; Microsoft Edge, y compris en navigation privée.

Gmail (facultatif)

Vous prévient des nouveaux e-mails à l'écran et à la voix, résume les importants, aide à ranger la boîte. Lecture seule par défaut ; ne supprime et n'envoie jamais rien.

Confiance et sécurité

Tout reste chez vous

Vos notes, souvenirs et rappels sont enregistrés dans le dossier de JARVIS sur votre PC. Aucune télémétrie, aucun compte à créer, aucune donnée envoyée à l'auteur.

Actions limitées et confirmées

JARVIS n'exécute que des actions prévues. Il ne supprime ni ne déplace de fichiers, n'éteint pas le PC, n'exécute pas de scripts. Les actions sensibles demandent votre confirmation.

Gmail prudent

Lecture seule par défaut. Le contenu de vos e-mails n'est écrit ni sur le disque ni dans les journaux, et les instructions cachées dans un message sont ignorées.

Code lisible

JARVIS est écrit en Python, en clair, avec sa suite de tests. Vous pouvez tout lire avant de l'installer. L'empreinte SHA-256 permet de vérifier que le fichier n'a pas été modifié.

Questions fréquentes

Pourquoi faut-il installer Python et Ollama ?

JARVIS est un programme Python : il a besoin de Python pour fonctionner. Ollama fournit l'intelligence artificielle locale, ce qui évite d'envoyer vos conversations à un service en ligne et d'avoir un abonnement.

Le micro ne fonctionne pas.

Vérifiez que le micro est autorisé dans Windows (Paramètres, Confidentialité et sécurité, Microphone) et choisissez-le dans les paramètres de JARVIS (onglet Écoute). Le micro a besoin du composant PyAudio : l'installateur l'installe, mais il peut échouer avec une version de Python trop récente. Dans ce cas, installez Python 3.13. Vous pouvez toujours taper vos commandes.

Faut-il Internet pour utiliser JARVIS ?

Pour l'installation, oui. Ensuite, la plupart des fonctions marchent hors ligne (commandes, notes, rappels, IA locale). La reconnaissance vocale utilise un service de Google et demande donc Internet ; la saisie au clavier n'en a pas besoin. Gmail et les recherches web en ont évidemment besoin.

L'extraction est incomplète (je ne vois que main.py, ou il manque des fichiers).

Recommencez dans un nouveau dossier vide : clic droit sur le ZIP, « Extraire tout… », choisissez un dossier qui n'existe pas encore. Vérifiez que vous regardez bien le dossier extrait (icône de dossier normale) et non le ZIP lui-même (icône avec une fermeture éclair). Autre méthode, fiable : ouvrez PowerShell dans le dossier où se trouve le ZIP (clic droit dans le dossier, « Ouvrir dans le Terminal »), puis tapez Expand-Archive -Path .\JARVIS-3.0.0.zip -DestinationPath $HOME\JARVIS : tout est alors extrait dans C:\Users\votre-nom\JARVIS. Si des fichiers disparaissent juste après l'extraction, votre antivirus les met peut-être en quarantaine : autorisez le dossier, ou vérifiez l'historique de protection de Windows Sécurité.

Windows bloque le fichier ou affiche un avertissement.

C'est normal pour un programme qui ne vient pas d'un éditeur connu. Cliquez sur « Informations complémentaires » puis « Exécuter quand même ». Vous pouvez ouvrir les fichiers .bat avec le Bloc-notes pour voir exactement ce qu'ils font, et vérifier l'empreinte SHA-256 du ZIP.

Comment connecter Gmail ?

Gmail est facultatif et demande de créer, une fois, un identifiant Google gratuit : la marche à suivre complète, étape par étape, est dans le fichier README.md fourni (section Gmail). Ensuite, dites « connecte Gmail ». Astuce : tant que votre application Google est en mode « Test », Google coupe l'autorisation tous les 7 jours ; le README explique comment l'éviter.

Ça marche sur Mac, Linux ou Windows 10 ?

JARVIS est conçu et utilisé sur Windows 11. Il pilote Windows (ouverture de logiciels, dossiers, etc.) : il n'est pas pris en charge sur macOS ni Linux. Windows 10 n'a pas été testé.

Comment désinstaller JARVIS ?

Supprimez simplement son dossier (et le raccourci du Bureau). JARVIS n'installe rien ailleurs dans Windows. Pour retirer l'IA locale : désinstallez Ollama, ou tapez ollama rm qwen2.5:1.5b. Si vous aviez connecté Gmail, dites d'abord « déconnecte Gmail ».

Quelque chose ne va pas après l'installation.

Lancez lancer_jarvis.bat --diagnostic : il affiche l'état de chaque composant (Python, voix, micro, Ollama, mémoire…). Le journal technique est dans le dossier logs et ne contient aucune de vos conversations.
